# PetShop Amigo Fiel – Projeto da Disciplina (Fase 1)

Site estático em HTML puro (sem CSS, Bootstrap ou JavaScript) com cabeçalho, produtos de 3 categorias, serviços com tele-busca e rodapé.

- Site publicado: https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/
- Ajuda com as funcionalidades: `ajuda.html`

## Como publicar no GitHub Pages
1. Crie um repositório público e envie todos os arquivos (com `index.html` na raiz).
2. Vá em **Settings > Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`.
4. Aguarde alguns minutos e acesse o link gerado.
